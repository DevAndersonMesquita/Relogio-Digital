⏰ Relógio Digital

Um relógio digital em tempo real desenvolvido com HTML, CSS e JavaScript, exibindo horas, minutos e segundos atualizados dinamicamente.

🔗 Acesse o projeto online:
https://relogio-digital-five-rust.vercel.app

🚀 Sobre o Projeto

Este projeto foi desenvolvido com o objetivo de praticar:

Manipulação do DOM

Funções em JavaScript

Uso de Date()

Atualização automática com setInterval

Estilização moderna com CSS

O relógio atualiza automaticamente a cada segundo, exibindo o horário atual do sistema do usuário.

🛠️ Tecnologias Utilizadas

HTML5

CSS3

JavaScript (Vanilla JS)

Deploy na Vercel

📌 Funcionalidades

✅ Exibição de horas, minutos e segundos

✅ Atualização automática a cada 1 segundo

✅ Formatação com dois dígitos (ex: 09:05:03)

✅ Layout centralizado e moderno

✅ Responsivo

🧠 Aprendizados

Durante o desenvolvimento, pratiquei:
